SITE DOKI DOKI — VERSÃO ATUALIZADA PARA AS PRÁTICAS DE CSS

Esta versão reúne os três tipos de CSS estudados:
- CSS externo: style.css compartilhado pelas páginas HTML e responsável pelo layout.
- CSS interno/incorporado: bloco <style> no <head> do index.html.
- CSS inline: atributos style em alguns elementos do index.html.

Práticas adicionadas:
- Aside com position: fixed, permanecendo na lateral durante a rolagem.
- Agrupamento de 7 imagens usando Flexbox e organização em camadas com position/z-index.
- Clique nas imagens para fazê-las desaparecer.
- Botão "Mostrar todas" para restaurar as 7 imagens.
- Menu dropdown dentro do nav.
- Layout responsivo para telas menores.

Estrutura principal:
- Header: cabeçalho no topo.
- Nav: menu horizontal abaixo do cabeçalho.
- Aside: barra lateral fixa.
- Main: conteúdo principal à direita.
- Footer: rodapé.

O conteúdo, os links e as imagens existentes foram preservados.
